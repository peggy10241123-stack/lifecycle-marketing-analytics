# Lifecycle Marketing & CRM Analytics

**SQL | Tableau | Customer Segmentation | Campaign Performance | Retention & Reactivation**

## Project Overview

This portfolio project explores how lifecycle marketing campaigns can improve user engagement, retention, reactivation, and monetization on a live entertainment and social platform.

I analyzed four CRM campaigns and an always-on SMS reactivation program using SQL for data preparation, modeling, and KPI calculation, and Tableau for visualization and business storytelling.

The analysis focuses on identifying conversion bottlenecks, understanding differences across customer segments, and translating behavioral data into actionable CRM recommendations.

## Business Questions

- Where do users drop off across different campaign funnels?
- How does engagement differ by customer value tier and lifecycle stage?
- Which customer segments contribute the most revenue?
- How does reactivation performance vary by inactivity duration?
- What opportunities exist to improve campaign targeting, engagement, and monetization?

## Key Findings

| Campaign | Key Finding |
|---|---|
| **Puzzle Event** | 750 users participated, with a 37.3% completion rate among participants. |
| **7-Day Check-in** | 94.3% of visitors unlocked the campaign, but only 37.5% completed all seven check-ins. |
| **King's Return** | 64.9% of eligible users returned; 20.5% of gift claimers reached the 30-day login milestone. |
| **Fortune Recharge** | Total observed recharge revenue reached 164,294, with 59.3% generated by 29 users in the 1,500+ spend band. |
| **SMS Reactivation** | Reactivation rates ranged from 46.6% for the 3-day inactivity segment to 8.1% for the 30-day segment. |

## Data Disclaimer

This is a portfolio case study. The four campaign datasets were synthetically reconstructed based on real CRM campaign mechanics. The SMS analysis uses scaled historical operational figures. Findings are intended to demonstrate analytical methodology and business reasoning rather than establish experimentally verified incremental campaign impact.
